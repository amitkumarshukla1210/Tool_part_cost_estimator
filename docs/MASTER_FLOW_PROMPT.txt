========================================================
FLOW FOR OPTION 1 & 2 (mechanical parts)
========================================================
STEP 1 – UPLOAD & PART REGISTER
- Upload a single part or an assembly. For assemblies, split into parts automatically, show the part tree and thumbnails; I tick which parts to cost (others marked Bought-out / Existing / Not required).
- For each part: Part code, Part name, Drawing rev no., Project, Material, Process (auto-suggested: plastic injection moulding, die casting, foundry, sheet metal multi-stage, sheet metal progressive, machined, bought-out), Annual volume, Programme life.
- Bulk upload by Excel template (part code, name, rev, file name, material, volume) for many parts at once.

STEP 2 – TOOL / MOULD CONCEPT DESIGN (automatic first proposal, engineer reviews)
- Moulds/dies: opening direction, parting line proposal, undercut detection → slides/lifters, cavity count & layout, core/cavity insert size, standard mould base selection, gate/runner type, cooling concept, ejection.
- Sheet metal: operation sequence (blank, draw, trim, pierce, form, fold…), multi-stage vs progressive, strip layout, stage-wise part shape, weight and tonnage.
- Output: concept 3D (blocks: mould base, inserts, slides) + 2D/PDF layout with dimensions. Detailed final tool design is expected in the engineer's CAD; allow upload of the final tool 3D/drawing to replace the concept.

STEP 3 – SIMULATION & ANALYSIS PAGE (new page)
- Plastic / die casting: wall-thickness map, draft-angle check, undercut map, sink/stress-mark risk areas, fill/pack/cooling time estimate → cycle time, injection pressure → clamp tonnage, machine selection.
- Sheet metal: formability checks (bend radius vs thickness, hole-to-edge, draw ratio/LDR, springback allowance), stage-wise force and press tonnage.
- Use open-source analytical/empirical methods first; list optional deeper FEA/flow options (e.g. CalculiX, OpenFOAM-based solvers) and their limits. Do not claim Moldflow-level accuracy.
- Generate a report with coloured pictures (problem areas marked), list of "Corrections required" (to R&D part design or to tool design), cycle time, tonnage, machine.

STEP 4 – DESIGN LOOP
- Status per part: Uploaded → Concept tool → Simulation → Corrections required → Revised (new rev) → Simulation OK → Tool design frozen.
- Each loop keeps history: rev, what changed, who, when, simulation result. Compare two revs side by side.

STEP 5 – TOOL COSTING PAGE (after "Simulation OK")
- Per tool/mould/stage tool: tool material & BOM, process-wise cost (cutting, CNC, EDM/wire cut, grinding, polishing, heat treatment, surface treatment, assembly), design, trial, supplier overhead & profit, packing, transport, country comparison and landed cost (as in my earlier sections A–E).

STEP 6 – PART COSTING PAGE (uses simulation data)
- RM (gross weight, yield, scrap credit), process cost from simulated cycle time and the selected machine's MHR (machine selection rules visible and editable — critical), secondary operations, rejection, overhead, profit, packing, tool amortisation, logistics, country comparison and landed cost.

STEP 7 – HISTORY & SCALE
- Every part keeps full history (revs, simulations, tool cost versions, part cost versions, rates used).
- Must handle ~10,000 3D parts: database (SQLite now, PostgreSQL later), file storage for CAD, fast search/filter by project, part code, rev, process, status, cost range.
- Dashboard: status of all parts, total tool cost and total BOM cost per project.

STEP 8 – DOWNLOADS
- For each part: tool cost and part cost with full backup data (all formulas, inputs, sources, rates and rate month) as PDF and Excel.
- For a project: consolidated BOM cost and tool cost in one Excel + PDF.

FLOW FOR OPTION 3 (wire harness & PCB)
========================================================
PAGE A – BOM EXTRACTION
- Upload harness CAD/PDF. Read the BOM table from the drawing (text-based PDF first; scanned PDF via OCR as later stage) and from CAD/XML where available.

PAGE B – BOM COSTING

- PCB: component cost from my part library (and optional distributor APIs that allow use with a free key), bare board cost, SMT/THT assembly cost, testing.
- Download BOM + cost in Excel/PDF with backup.
