# Design to Cost V0

First numbered version. Everything built up to roadmap stage 25:

- Costing: RM, tool (moulds, dies), part cost, country comparison, landed cost, harness and PCB.
- Capacity 0 to 3000 t with machines, bases and rates; simulation, 3D design correction, FEA (Gmsh + CalculiX).
- Production tool design for plastic, die casting, foundry, sheet metal (progressive and stage), EPS and blow: numbered parts, STEP, drawings, BOM, bought-out list,
  purchase orders, supplier ZIP, toolmaker review, supplier quotes.
- Progressive vs stage-die comparison for sheet metal.
- Dashboard with Delete part / project; logo and name on Excel, PDF and PowerPoint downloads.
- Backup, restore and upgrade by ZIP; local install scripts for Windows.
