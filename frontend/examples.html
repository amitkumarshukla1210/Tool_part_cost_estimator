Replace example values

Every value still marked EXAMPLE, counted by category. Work through them step by step: type the real value and click Replace, or Keep when the example value is already right. A replaced rate is saved as a new approved version (old versions are kept), so stored costs only change when you recalculate them. The “Uses example rates” warnings disappear once every value a cost uses is replaced.
