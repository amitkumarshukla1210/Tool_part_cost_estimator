Safety

Backup, restore and upgrade

Version …. A backup holds your projects and parts (data), your CAD files (storage) and your rates, machines and formulas (master data).

Backups on this computer

Download a copy and keep it outside this computer too. Restoring first makes a safety backup of what is there now.

Upgrade to a newer version (V1, V2 …)

  1. On GitHub download the ZIP of the new version (green Code button → Download ZIP, or the file in releases/V1/) and save it on your laptop.
  2. Close the tool window, put the ZIP in the folder upgrades (next to Start_Tool.bat) and double-click Upgrade_Tool.bat.
  3. It backs up everything, puts the new files over the old ones, keeps your projects, CAD files and master data, adds the new master-data rows and checks itself. If anything fails it puts the old version back.
  4. Start the tool again with Start_Tool.bat.
