Update the app

This stops the app, installs the latest version from the Windows kit, then restarts it. Your data is backed up before updating.

Manual host maintenance: close the app window, double-click DTC_Update.bat (a backup is made first), then DTC_Start.bat. To go back: DTC_Rollback.bat. To put a backup back: DTC_Restore.bat.

Logo

The AI assistant answers questions about parts, costs, tools, suppliers and rates in plain language, in a panel on every page (Ask AI). Everyone who is logged in may use it. It sees only what that user may see (role and tool groups) and it can never approve, change or delete anything. Every question is written to the Activity log. Questions and the data the assistant looks up are sent to Anthropic (Claude) to answer them.

Get a key on console.anthropic.com → API keys (your company's Anthropic account; usage is billed there). The key is kept in this installation's project database (never in GitHub) and is never shown again, only its last 4 characters. Backups contain it, so keep backup files safe.
