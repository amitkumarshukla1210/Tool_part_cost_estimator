How to write rules

Rules work like an Excel formula without cells, e.g. max(4, ceil(cavities * projected_area_cm2 / 8)) or cavities if hot_runner else 0. Use + − * / ( ), comparisons, a if condition else b, and / or / not and ceil, floor, round, min, max, abs, sqrt. Line cost = quantity × (bought-out cost + weight × material rate/kg + hours × process rate/h).
